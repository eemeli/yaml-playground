# Browser Playground for `yaml`

This repository:

1. Packages the browser build of `yaml` into a minified UMD package `yaml.min.js`.
2. Provides an interactive playground for testing and playing with YAML

For the `yaml.min.js` build,
this repo expects to find [`eemeli/yaml`](https://github.com/eemeli/yaml) next to itself as `yaml/`.
